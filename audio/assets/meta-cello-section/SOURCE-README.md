# String Studio — cello sample pack (v1)

Real-instrument multisamples derived from **VSCO 2 Community Edition** by
Versilian Studios. Licensed CC0-1.0 (public domain).

- **Source URL**: https://github.com/sgossner/VSCO-2-CE
- **Pack version**: 1
- **Sample rate**: 48000 Hz, mono, 24-bit PCM WAV
- **Render duration**: 2.5s per zone (trimmed, peak-normalized
  to −3 dBFS, 50ms tail fade)
- **Zone count**: 26
- **Total size**: 8.9 MB

Each zone is one (rootPitch, velocity layer) selected from VSCO's broader
multisample set. The runtime SampleLoader picks the closest zone to an
incoming MIDI note and pitch-shifts via `playbackRate`.

For the full VSCO 2 CE library (more pitches, more articulations, room mic
options), download from the source repo above.
